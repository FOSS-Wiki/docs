# FOSS Wiki Docs

Assorted documentation used for [https://foss.wiki](https://foss.wiki) and its supporting services. Click the title of a section to open the directory with the instructions and relevant files for that service.

## Services

### [Database Backups](./db-backup)

For daily database (MariaDB or MySQL) backups uploaded to a S3-compatible provider that is compressed and encrypted.

### [Wiki Content Archive](./wiki-archive)

For weekly exports of the wiki content as .ZIM and .XML files to a webserver with the ability to auto upload to the Internet Archive uploading and mirroring the archives.
