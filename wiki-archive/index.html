This site publishes weekly archives of WIKINAME and stores them for two weeks. All files are accessible both on this webpage or via rsync at ARCHIVEDOMAIN::wikiname. The text dumps are uploaded to the Internet Archive after the archive is made; images are excluded as our image policy is not compatible with their upload guidelines.

To mirror the archives, you can do so using rsync:

  1. Attempt a dry-run with rsync -rltpvnH --progress --safe-links --delete-delay --delay-updates ARCHIVEDOMAIN::wikiname /srv/repo/wikiname/
  2. Once it is verified to work, run the first sync (same command without -n): rsync -rltpvH --progress --safe-links --delete-delay --delay-updates ARCHIVEDOMAIN::wikiname /srv/repo/wikiname/
  3. Once you have done the first sync you can add it to crontab using 0 2 * * 2 rsync -rlptH --safe-links --delete-delay --delay-updates ARCHIVEDOMAIN::wikiname /srv/repo/wikiname/ to sync from the archive weekly on Tuesday at 2AM.

You can sync from the server at any time, however we run the script weekly on Monday at 02:00 UTC, so mirroring more than weekly will not change anything. The script can take up to an hour to run, so please note that between the final dump being produced and the cleanup of the old files there will be the last 3 weeks of files available. Hence we recommend not syncing 3 hours either side of the time the script is due to run (Sunday 23:00 UTC to Monday 05:00 UTC). Also note the times shown here are in your local timezone.
